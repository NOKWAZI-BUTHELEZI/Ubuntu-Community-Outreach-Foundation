## Project Overview

Ubuntu Community Outreach Foundation is a community-focused non-profit organisation established to support and empower individuals and families through community outreach, educational support and community development programmes.

This website has been developed to provide information about the organisation, its mission, services, community activities and contact information. The website is designed to make it easier for community members, volunteers, donors and potential partners to learn about the organisation and get involved.

The project is being developed in three parts. Part 1 focuses on creating the HTML structure and basic content. Part 2 focuses on CSS styling, layout, typography and responsive design. Part 3 will add JavaScript functionality, form validation and search engine optimisation.

## Website Goals and Objectives

The main goals of the website are to:

- Raise awareness about Ubuntu Community Outreach Foundation.
- Provide information about the organisation and its mission.
- Explain the services and programmes offered.
- Showcase community outreach activities.
- Provide contact information for enquiries.
- Encourage community members, volunteers and potential partners to get involved.

## Part 2 - Designing the Visuals: CSS Styling and Responsive Design

### CSS Styling

The Ubuntu Community Outreach Foundation website was styled using an external CSS stylesheet named `style.css`, located inside the `css` folder.

A CSS reset was implemented to provide consistent styling across different browsers. Base styles were also established for the body, headings, paragraphs, navigation, forms, images and footer.

### Typography

Typography was designed using Arial, Helvetica, sans-serif.

Different font sizes, font weights, line heights and spacing were used for headings, paragraphs and navigation links to create a clear and readable website.

### Layout Structure

CSS Flexbox and Grid layout techniques were used to create a clear website structure.

The layout includes:

- Header section.
- Navigation menu.
- Main content area.
- Gallery section.
- Enquiry form.
- Footer section.

### Visual Design

The website uses a green colour scheme to represent growth, community and development.

Background colours, borders, spacing, buttons and hover effects were added to improve the visual appearance and usability of the website.

### Responsive Design

CSS media queries were added to help the website adapt to different screen sizes.

The navigation changes on smaller screens, while content padding and heading sizes are adjusted for mobile devices.

The main responsive breakpoints used are:

- Desktop: 1200px and above.
- Tablet: 768px.
- Mobile: 480px and below.

Relative units such as rem, em and percentages were used where appropriate to support responsive sizing.

### Responsive Images

The website uses responsive image techniques to ensure that images adjust to the available screen size.

Images are set to a maximum width of 100% and maintain their aspect ratio.
